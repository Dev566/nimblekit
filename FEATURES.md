# Features & Roadmap

## ✅ MVP Features (Implemented)
- **Calculator**: Basic arithmetic with keyboard support.
- **Unit Converter**: Length, Weight, Temperature, Volume.
- **Percentage Calculator**: % of value, % change, discount.
- **Age Calculator**: Calculate age and date differences.
- **Text Tools**: Word count, character count, case conversion (Upper, Lower, Title, Sentence, Reverse).
- **Text Cleaner**: Remove extra spaces, line breaks, duplicate lines.
- **URL Shortener**: Client-side (localStorage) shortener with redirect support.
- **QR Code Generator**: Generate and download QR codes.
- **BMI Calculator**: Calculate BMI with category indicators (Metric/Imperial).
- **Loan Calculator**: Calculate Monthly Payment (EMI), Total Interest, Total Payment.
- **JSON Formatter**: Prettify, Minify, Validate JSON with error highlighting.
- **Theme Switcher**: Vibrant Blue / Warm Sunset.
- **Recent Tools**: Auto-saved history of used tools.
- **Request Form**: Netlify Forms integration.
